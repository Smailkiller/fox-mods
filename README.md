# fox-mods

Маркетплейс модов для Claude Code.

| Мод | Что делает |
| --- | --- |
| [fox-on-prompt](plugins/fox-on-prompt) | Над полем ввода: слева полоса заполнения контекста по блокам с процентами, справа пиксельный лис и крабик курят кальян |

## Установка

```bash
claude plugin marketplace add Smailkiller/fox-mods
claude plugin install fox-on-prompt@fox-mods
```

Затем откройте новый чат. Нужен Claude Code 2.1.289 или новее (моды пока в раннем доступе).
